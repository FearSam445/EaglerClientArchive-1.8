# Prompt Master

Prompt Master turns a rough, quickly typed prompt into a clear, well-structured one before you send it to Claude.

- **One click:** start typing in the prompt box and a **✨ Prompt Master** button appears just above it (terminal and desktop app). Press it and your draft is replaced with the improved prompt, ready to review and send.
- **Anywhere:** run `/prompt-master <your rough prompt>` on any surface (terminal, desktop, VS Code, mobile). The rewritten prompt is placed in the prompt box, or shown as output where there is no box.

It keeps your intent, file names, code and constraints, adds a clear goal and definition of done, and never sends anything on its own: you always review before pressing Enter. Rewrites use your own Claude session's credentials.
